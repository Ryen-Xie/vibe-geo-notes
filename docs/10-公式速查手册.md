## A. 时间类

### A1 地方时换算
```
T₂ = T₁ ± (λ₂ − λ₁) / 15        （单位：小时；东加西减）
ΔT(分钟) = Δλ × 4
```
推导：地球 24 小时转 360°，1 小时转 15°，故 1° = 4 分钟。

### A2 时区与区时
```
时区号 = round(λ / 15)     λ 东经为正、西经为负
中央经线 = 15° × 时区号
区时差 = 时区号之差（小时）
```

### A3 日期变更判断
设 0 时经线为 λ₀，则"新的一天"所占经度 = 从 λ₀ 向东到 180° 的经度差。
```
新一天占比 = (180° − λ₀ + 360) mod 360  / 360
```
（λ₀ 取东经度数，注意跨 0° 的处理）

### A4 恒星日与太阳日
```
恒星日 = 23h56m04.09s = 86164.09 s
太阳日 = 86400 s
差值 ≈ 235.9 s ≈ 3m56s
```
推导：`86400 × (1 − 1/365.2422) ≈ 86164`。

## B. 太阳几何

### B1 正午太阳高度
```
H = 90° − |φ − δ|
```
- φ 当地纬度（北正南负），δ 直射点纬度（北正南负）
- H < 0 表示太阳不升起（极夜）

### B2 直射点纬度（按日期估算）
```
δ ≈ 23.44° × sin( 360° × (N − 81) / 365 )      N 为一年中的第几天
```
（近似式，误差 1° 以内，够画动画用。）

### B3 昼长
```
cos ω₀ = − tan φ · tan δ
昼长 = 2ω₀ / 15°   （小时）
```
- 若 `−tanφ·tanδ ≥ 1` → 极昼，昼长 24 h
- 若 `−tanφ·tanδ ≤ −1` → 极夜，昼长 0 h

### B4 日出日落地方时
```
日出 = 12 − 昼长/2
日落 = 12 + 昼长/2
```
（不考虑大气折射与时差方程；真实日出会早几分钟，可用 NOAA 算法修正。）

### B5 影长与影向
```
影长 L = h / tan H
影子方向 = 太阳方位的反方向
```
正午影向：直射点在当地以南 → 影子朝北；以北 → 影子朝南。

### B6 极昼区子夜太阳高度
```
h_min = φ + δ − 90°
```
（φ、δ 同半球取正；φ = 90° 时 h_min = δ，即北极点太阳高度全天恒定。）

### B7 太阳能板最佳倾角（固定式）
```
倾角 β ≈ 90° − H_正午 = |φ − δ|
```
工程上常取"当地纬度 ± 5°"作为年最优固定倾角（按当地纬度粗算即可）。

## C. 地球物理

### C1 自转线速度
```
v = 1670 × cos φ  (km/h)
```
赤道约 1670 km/h；30° 约 1446；60° 约 835。

### C2 昼夜弧比（用晨昏线切纬线圈）
```
昼弧占比 = 昼长 / 24
```

### C3 太阳常数与全球平均
```
TSI ≈ 1361 W/m²   （大气顶、垂直于光线）
全球平均 ≈ TSI / 4 ≈ 340 W/m²   （球面平均）
考虑反照率（约 0.3）后地表吸收 ≈ 240 W/m²
```

## D. 可直接跑的代码

### D1 Python：算某地某日的昼长与正午太阳高度

```python
import math

def solar_declination(doy):
    """按一年中的第几天估算太阳直射点纬度（度）"""
    return 23.44 * math.sin(math.radians(360 * (doy - 81) / 365))

def day_length(lat, dec):
    """昼长（小时）。lat/dec 单位为度，北正南负"""
    x = -math.tan(math.radians(lat)) * math.tan(math.radians(dec))
    if x >= 1:   return 24.0
    if x <= -1:  return 0.0
    w0 = math.degrees(math.acos(x))     # 半昼弧（度）
    return 2 * w0 / 15.0

def noon_altitude(lat, dec):
    return 90 - abs(lat - dec)

# 示例：北京 39.9°N，夏至（约第 172 天）
dec = solar_declination(172)
print(round(dec, 2), round(day_length(39.9, dec), 2), round(noon_altitude(39.9, dec), 2))
```

### D2 JavaScript：给 three.js 摆太阳位置

```js
// 用一个方向向量表示太阳方向（简化：只考虑赤纬与时角）
function sunDirection(latDeg, decDeg, hourAngleDeg) {
  const lat = latDeg * Math.PI / 180;
  const dec = decDeg * Math.PI / 180;
  const H   = hourAngleDeg * Math.PI / 180;
  // 地平坐标 → 单位向量（z 向上）
  const alt = Math.asin(Math.sin(lat) * Math.sin(dec) +
                        Math.cos(lat) * Math.cos(dec) * Math.cos(H));
  const az  = Math.atan2(-Math.cos(dec) * Math.sin(H),
                         Math.sin(dec) * Math.cos(lat) -
                         Math.cos(dec) * Math.sin(lat) * Math.cos(H));
  return { altitude: alt * 180 / Math.PI, azimuth: (az * 180 / Math.PI + 360) % 360 };
}
```

> 提示：做动画时**不要**逐帧调用文生视频模型，而是先用这段代码算出每帧的光照方向，再统一渲染/生成，否则晨昏线会漂。

## F. 三个"一句话推导"（讲给别人听时用）

1. **为什么 1° 是 4 分钟**：24 小时 ÷ 360° = 1/15 小时 = 4 分钟。
2. **为什么极圈 = 90° − 黄赤交角**：极昼最低纬度 = 90° − δ，二至日 δ 取极值 23°26′。
3. **为什么全球平均只有 1/4 的太阳常数**：球体截面积 πr²、表面积 4πr²，比值为 1/4。
