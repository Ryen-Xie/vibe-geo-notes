## 1. 课标里的"地球"在哪几条

《普通高中地理课程标准（2017 年版 2020 年修订）》把地球相关内容拆在两个模块：

### 必修 · 地理1（地球科学基础）

| 条目 | 内容要求（要点转述） |
| --- | --- |
| 1.1 | 运用资料描述地球所处的宇宙环境，说明太阳对地球的影响 |
| 1.2 | 运用示意图说明地球的圈层结构 |
| 1.3 | 运用地质年代表等资料简要描述地球的演化过程 |
| 1.5 | 说明大气的组成与垂直分层及其与生产生活的联系 |
| 1.6 | 说明大气受热过程与热力环流原理，并解释相关现象 |
| 1.7 | 说明水循环的过程及其地理意义 |
| 1.8 | 说明海水性质和运动对人类活动的影响 |
| 1.9 / 1.10 | 土壤形成因素 / 主要植被与自然环境的关系 |

### 选择性必修1 · 自然地理基础

| 条目 | 内容要求（要点转述） |
| --- | --- |
| 1.1 | **结合实例，说明地球运动的地理意义** ← 地球专题的"总纲" |
| 1.2 | 运用示意图说明岩石圈物质循环过程（含板块、内力作用） |
| 1.3 | 解释内力和外力对地表形态变化的影响 |
| 1.4-1.8 | 天气系统、气压带风带、陆地水体、洋流、海气相互作用 |
| 1.9 | 自然环境的整体性与地域分异 |

**读法**：必修地理1 讲"地球是什么样"，选必1 讲"地球怎么动、动了有什么后果"。
做视频时，选题挂在 1.1 这条上最容易起量——它天然要求"结合实例"，正好对应生活钩子。

> 另注：2025 年日常修订版课标中新增了"海洋地理"相关内容（含海底地形、板块构造学说、海洋权益等条目），
> 若要做"海洋 + 板块"专题，可留意新版表述。查版本时以教育部/人教社官方发布件为准。

## 3. 考纲（旧）与新高考的差别

- **旧全国卷考纲**（教育部教育考试院发布，最后以 2019 版为代表）把"地球运动的地理意义"明确列在必考内容第一部分"宇宙中的地球"下，属于自然地理主干。
- **新高考（各省自主命题）**不再出考纲，改用"课标 + 学业质量水平"为依据，但知识边界基本一致。
- 实际差异：新高考更爱把地球运动**藏在情境里**（光伏支架倾角、楼盘采光、航班时刻、圭表测影、极地科考），
  而不是直接给一张光照图。做视频时，"生活情境 + 老原理"是新高考最对味的形式。

## 4. 考频与分值：经验区间（务必自己复核）

以下为公开教研材料中反复出现的**量级判断**，用于选题排序，不作为精确统计数据引用：

| 知识块 | 分值占比（经验区间） | 常见呈现 |
| --- | --- | --- |
| 地球运动（自转+公转） | 约 8%-12% | 选择题 1-2 组（光照图、时间计算、影长方位），偶见综合题小问 |
| 大气（受热、环流、天气系统） | 约 15%-20% | 选择题 + 综合题（气候成因、天气过程） |
| 水（水循环、洋流、海气） | 约 12%-18% | 综合题高频 |
| 地貌与内外力 | 约 12%-15% | 景观图判读、形成过程描述 |
| 圈层与板块 | 约 4%-6% | 常与地震、火山、地貌合并考 |

### 命题趋势（近十年可观察到的四条）

1. **情境生活化**：影子、采光、太阳能板、传统计时工具（圭表、日晷）、二十四节气。
2. **图表轻量化**：纯经纬网定位题减少，景观图、剖面图、统计曲线增多。
3. **过程化设问**："说明……的形成过程"比"判断……是"更常见，要求讲清因果链。
4. **跨模块融合**：地球运动 + 传统文化、地球运动 + 农业/建筑/交通。

## 5. 高频易错点清单（做内容时优先打这些）

| # | 易错点 | 正确表述 |
| --- | --- | --- |
| 1 | 地方时 vs 区时混用 | 地方时按经度差 1°=4 分钟；区时按整时区，中央经线 15°×n |
| 2 | 日界线只认 180° | 实际有两条：人为日界线（约 180° 经线）+ 自然日界线（0 时所在经线） |
| 3 | 认为夏至地球离太阳最近 | 近日点在 1 月初，远日在 7 月初；四季由黄赤交角决定 |
| 4 | 认为昼夜长短由距离决定 | 由太阳直射点纬度与当地纬度共同决定 |
| 5 | 晨昏线画错 | 晨昏线是大圆，过地心，与太阳光线垂直；只有春秋分才过极点 |
| 6 | 极昼范围算错 | 极昼最低纬度 = 90° − 直射点纬度 |
| 7 | 正午太阳方位判断错 | 看直射点在南/北：直射点在当地以北则正北，以南则正南，重合则天顶 |
| 8 | 地转偏向力方向 | 北半球右偏、南半球左偏、赤道不偏；只改变方向不改变速度大小 |
| 9 | 岩石圈 = 地壳 | 岩石圈 = 地壳 + 上地幔顶部（软流层以上） |
| 10 | 横波能穿过地核 | 横波不能在液态外核传播，这正是发现液态外核的关键证据 |
