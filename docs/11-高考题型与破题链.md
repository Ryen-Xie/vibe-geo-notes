# 11 · 高考题型与破题链

> 五种高频题型的"固定动作"。每种给：设问长相 → 四步破题 → 常见陷阱 → 自编示例（不抄真题）。

---

## 题型 1：时间/日期计算型

### 设问长相
"此时北京时间是……"、"该地的地方时约为……"、"此时全球新的一天占……"、"飞机起飞后到达时当地时间是……"

### 四步破题
1. **定参照**：题干给的是地方时、区时还是"太阳高度最大/影子最短"（=地方时 12:00）？
2. **定经度**：由图中位置、等太阳高度线、晨昏线切点推出经度。
3. **算差值**：Δλ / 15 = ΔT（小时），或 Δλ × 4 = ΔT（分钟），东加西减。
4. **过日界线**：跨 180° 要改日期；跨 0 时经线也改日期（这是最容易漏的一步）。

### 陷阱
- 把"北京时间"当成"北京地方时"（116°E ≠ 120°E，差 16 分钟）。
- 只改钟点不改日期。
- 计算"新的一天占比"时，忘了新一天是"从 0 时经线向东到 180°"。

### 自编示例
某地正午时，太阳刚好位于天顶，此时北京时间是 15:20。该地的经度是多少？
> 正午 = 地方时 12:00；北京时间（120°E）为 15:20，相差 3h20min = 200 分钟 → 经度差 50°。
> 该地比北京时间晚 → 在 120°E 以西 50° → **70°E**。

## 题型 2：光照图 / 晨昏线判读型

### 设问长相
给一个带阴影的光照图（俯视/侧视），问"此时太阳直射点坐标""该日最可能是什么节气""甲乙丙三地昼长排序""晨线是哪一段"。

### 四步破题
1. **找直射点**：昼半球正中那条经线 = 直射经线（地方时 12:00）；直射纬度看晨昏线与极圈的关系。
2. **定节气**：晨昏线过极点 → 二分日；与极圈相切 → 二至日（切点在北 → 夏至/冬至需再看光照方向）。
3. **定晨昏**：沿自转方向，由夜入昼是晨线。
4. **比昼长**：看各点所在纬线圈被昼弧切的比例，或直接看纬度高低与半球。

### 陷阱
- 阴影方向反了（太阳在左，夜半球必须在右）。
- 把切点纬度当极圈纬度固定值（只有二至日才等于 66°34′）。
- 俯视图里把"自转方向"画反。

### 自编示例
北极圈上某点刚好出现极昼，太阳直射点在哪？
> 极昼最低纬度 = 90° − δ → 66°34′ = 90° − δ → δ = 23°26′N → **北回归线**，日期为夏至前后。

## 题型 3：昼夜长短 / 太阳高度型

### 设问长相
"该地昼长为……""比较三地正午太阳高度""该地一年中正午太阳高度最大值出现在……""楼间距至少应为……"

### 四步破题
1. **取纬度与日期**（换算成 δ）。
2. **套公式**：昼长用 `cosω₀ = −tanφ·tanδ`；高度用 `H = 90° − |φ − δ|`。
3. **判极值**：昼长最大值在夏至（北半球）；H 最大值在直射点经过当地时。
4. **做应用**：影长 `L = h/tanH`；楼间距按"冬至日最小 H"；光伏倾角 `β = |φ−δ|`。

### 陷阱
- 忘取绝对值导致 H > 90° 或负值。
- 用"昼最长"当"昼增长"。
- 楼间距按夏至算（应取全年最小正午高度，即冬至）。

### 自编示例
北纬 40° 的城市，楼高 30 m，冬至日正午太阳高度约 26.5°，两楼最小间距约多少？
> `L = 30 / tan(26.5°) ≈ 30 / 0.498 ≈ 60 m`。取安全系数后通常按 1:1.2 以上设计。

## 题型 4：太阳方位 / 影子型

### 设问长相
"该日日出方位是……""杆影朝向……""该地正午太阳位于……""北极星仰角……"

### 四步破题
1. **定半球与季节**：由日出方位或昼夜长短判断直射半球。
2. **定正午方位**：比较 φ 与 δ 的南北关系。
3. **定影子方向**：影子与太阳方位相反；正午影长最短。
4. **定北极星**：北半球北极星仰角 = 当地纬度（南半球看不到）。

### 陷阱
- 认为北半球太阳永远偏南（热带夏半年可偏北）。
- 用"影子朝东"推"太阳朝西"却忘记时间。
- 把北极星仰角当成"90°−纬度"。

### 自编示例
某地一年中正午影子始终朝北，且影长有两次最短。该地纬度范围？
> 影子始终朝北 → 太阳始终在正南 → 该地在南回归线以南（δ 最大 23°26′S 时太阳仍在正南）
> 影长两次最短 → 一年有两次直射 → 该地在南北回归线之间。
> 两条件同时满足 → **南回归线与赤道之间（0°~23°26′S）**。

## 题型 5：地貌 / 板块 / 气候成因型（过程描述）

### 设问长相
"说明该地貌的形成过程""分析该地多地震的原因""解释该地降水最多的季节及成因""从内外力角度说明××山的形成"

### 四步破题
1. **定位与背景**：经纬度/海陆位置/板块位置。
2. **找主导作用**：内力（板块、褶皱、断层、火山）还是外力（流水、风力、冰川、海浪、喀斯特）。
3. **排时序**：先有什么、后有什么（"先沉积成岩 → 后挤压褶皱 → 再抬升 → 最后被侵蚀"）。
4. **落结论**：形态 + 成因 + 证据（岩性、层理、颗粒磨圆度）。

### 陷阱
- 只写"板块碰撞"不写"谁俯冲谁"。
- 过程题写成罗列（"地势高、降水多、植被茂"），没有因果连接词。
- 气候成因只答"受季风影响"，不落到"哪个风带/哪个季风/什么地形"。

### 自编示例
说明某大河入海口三角洲的形成过程。
> 上游与中游携带大量泥沙（侵蚀 + 搬运）→ 到入海口流速骤减 → 加上海水顶托，泥沙堆积 →
> 反复堆积并受海浪与河流改道改造 → 形成三角洲。若流域建坝拦沙，三角洲会由"进"转"退"。

## 通用答题模板（过程描述类）

```
[时间/空间定位] → [动力条件：谁在起作用] → [物质基础：有什么可搬/可溶/可堆]
→ [过程：先…后…最终…] → [证据/结论]
```

三个必写的连接词：**由于……从而导致……最终形成……**
改卷时，这三个词往往就是得分点所在的结构信号。
