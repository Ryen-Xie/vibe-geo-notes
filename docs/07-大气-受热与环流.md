# 07 · 大气：受热、环流与风带（KP40-KP44）

> 地球宜居的第二个答案（第一个是"位置刚好"）：**一层会自己搬运热量的膜**。

---

## KP40 大气的垂直分层

| 分层 | 高度范围（中纬） | 温度变化 | 关键特征 |
| --- | --- | --- | --- |
| **对流层** | 0-12 km（低纬 17-18，中纬 10-12，高纬 8-9） | 随高度**递减**（约 0.6℃/100 m） | 集中约 3/4 大气质量与水汽；**天气现象都在这层**；对流旺盛 |
| **平流层** | 12-50 km | 随高度**递增**（臭氧吸收紫外线） | 22-27 km 处有**臭氧层**；气流平稳，适合飞行 |
| **高层大气** | 50 km 以上 | 先降后升 | 有**电离层**（约 80-500 km），反射无線电波 |

### 为什么对流层"越高越冷"
地面是它的热源：太阳先加热地面，地面再通过长波辐射和对流把热量往上送。离"火炉"越远越冷。

### 可视化点
- 一条温度曲线（横=温度，纵=高度）随镜头上升同步绘制，三层用三种颜色。曲线在平流层"折返向上"那一刻很抓人。
- 飞机巡航镜头：平流层平稳、云海在脚下——一句话讲完"为什么坐飞机不颠"。

## KP41 大气受热过程：三个环节

### 全链条
```
太阳短波辐射 →（穿过大气，被削弱一部分）→ 到达地面
        → 地面吸收升温 → 发出地面长波辐射
              → 大气吸收（CO₂、水汽）→ 大气升温
                    → 大气逆辐射（把热量还给地面）
```

### 削弱作用（三个）
| 作用 | 对象 | 表现 |
| --- | --- | --- |
| 吸收 | 臭氧吸紫外线，水汽/CO₂ 吸红外线 | 选择性吸收，可见光大部分透过 |
| 反射 | 云层、尘埃 | 云越厚，到达地面越少（阴天凉） |
| 散射 | 空气分子、尘埃 | 蓝光散射强 → 天空蓝；日出日落光程长 → 红 |

### 保温作用
**大气逆辐射**把部分热量"还"给地面，使夜间降温不至于过猛。
- 晴天：白天削弱少（热）、夜间逆辐射弱（冷）→ **昼夜温差大**；
- 阴天：白天削弱多、夜间逆辐射强 → **温差小**；
- 应用：人造烟幕防霜冻、地膜与温室、霜冻多出现在晴朗无风的夜晚。

### 可视化点
- 三支箭头动画：短波（黄，向下）、长波（红，向上）、逆辐射（红，向下）。三个箭头同时动，观众一看就懂。
- 对比实验：同一块地面，有云/无云两条温度曲线。

### 易错
- 认为"大气直接吸收太阳辐射升温"——大气对太阳短波辐射吸收很少，主要靠**地面**加热。
- 认为"温室效应是坏事"——它是地球保温的**必要机制**；问题在于人为增强导致的全球变暖。

## KP42 热力环流：一切风的起点

### 原理（四步）
1. 某地受热 → 空气**上升** → 近地面空气变少 → **近地面低压**、高空高压；
2. 某地冷却 → 空气**下沉** → 近地面**高压**、高空低压；
3. 同一水平面上，空气从**高压流向低压**；
4. 形成闭合环流。

### 三个经典实例
| 实例 | 白天 | 夜晚 |
| --- | --- | --- |
| 海陆风 | 陆地升温快 → 陆热海冷 → 风从海吹向陆（海风） | 陆地降温快 → 陆冷海热 → 风从陆吹向海（陆风） |
| 山谷风 | 山坡受热快 → 风沿坡上升（谷风） | 山坡冷却快 → 冷空气沿坡下沉（山风） |
| 城市热岛 | 城区气温高 → 城区上升、郊区下沉 → 近地面风由郊区吹向城区 | —— |

### 可视化点
- 一个"环形箭头"闭合圈子，热源处箭头向上，冷源处向下。把热源位置一移动，整个环流实时重算——这是最能体现"模型"感的镜头。
- 城市热岛：俯视一个城市，热气柱上升，四周箭头向内汇聚。

### 易错
- 把"近地面低压"说成"高空也低压"——近地面与高空气压**相反**。
- 忘记"同一水平面"这个前提（气压比较必须在同一高度）。

## KP43 气压带与风带（七压六带）

### 形成逻辑（记住这条链就够）
```
赤道受热上升 → 赤道低压带
高空向两极流动 → 在 30° 附近堆积下沉 → 副热带高压带
30° 与 60° 之间气流旭合上升 → 副极地低压带
两极冷却下沉 → 极地高压带
```
共 **7 个气压带**（赤道低压 1 + 副热带高压 2 + 副极地低压 2 + 极地高压 2）。

### 六个风带
| 风带 | 纬度 | 北半球风向 | 南半球风向 |
| --- | --- | --- | --- |
| 极地东风带 | 60°-90° | 东北风 | 东南风 |
| 中纬西风带 | 30°-60° | 西南风 | 西北风 |
| 低纬信风带 | 0°-30° | 东北信风 | 东南信风 |

> 风向为什么"斜"？因为**地转偏向力**在起作用（KP14 的直接应用）。这一句能把两集串起来。

### 季节移动
气压带风带随太阳直射点移动，整体**北移（夏半年）/南移（冬半年）**，幅度约 5°-10°。
这是季风、地中海气候、热带草原气候干湿季的总开关。

### 可视化点
- 一个"地球 + 7 条环带"的俯视图，气压带用颜色（低压=暖色上升、高压=冷色下沉），风带用斜箭头。
- 让整条环带随季节南北平移 5°-10°，同时地面雨带跟着走——"雨带随季节移动"这张图价值极高。

### 易错
- 把"副热带高压"当成"热"（它是**动力**成因的下沉高压，与热力成因的赤道低压不同）。
- 忘记风向要加偏转（"西风带"在北半球是**西南风**，不是"正西风"）。

## KP44 季风与气候成因

### 东亚季风（最强）
- 成因：**海陆热力性质差异**（陆地比热小、升温快）；
- 冬季：亚洲高压 → 风从陆地吹向海洋 → 西北风，寒冷干燥；
- 夏季：亚洲低压（印度低压）→ 风从海洋吹向陆地 → 东南风，温暖湿润。

### 南亚季风（更复杂）
- 夏季**西南季风**：东南信风越过赤道右偏 + 海陆热力差异 + 气压带风带北移共同作用；
- 冬季**东北季风**：受亚洲高压影响。

### 气候成因的五个抓手（综合题模板）
| 抓手 | 说明 |
| --- | --- |
| 纬度位置 | 决定热量带与太阳高度 |
| 海陆位置 | 决定大陆性/海洋性、降水多少 |
| 大气环流 | 气压带风带、季风、锋面 |
| 地形 | 海拔、逆风/背风、对气流的阻挡 |
| 洋流 | 暖流增温增湿，寒流降温减湿 |

### 可视化点
- 东亚季风：一张地图，冬季箭头（蓝）从西北压向东南，夏季箭头（红）反向，同时给出同一城市的降水柱状图变化。
- "为什么南亚夏天会下那么多雨"：把喜马拉雅山与西南季风叠在一起，地形抬升 + 水汽输送，一条因果链。
