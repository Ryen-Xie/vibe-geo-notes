# 02 · 知识图谱总览（地球专题）

一张用来"排系列"的地图。每个知识点有唯一编号 `KP-nn`，可以在 `data/knowledge-points.json` 里被脚本直接读取。

---

## 1. 三条主干链（做系列就按这三条走）

### 主干 A：从宇宙到地球（"我们为什么在这"）

```
KP01 天体与天体系统
   └─ KP02 太阳系结构与行星分类
        └─ KP03 地球的普通性与特殊性（存在生命的条件）
             └─ KP04 太阳辐射与太阳常数
                  └─ KP05 太阳活动与日地相互影响
                       └─ KP06 地质年代与地球演化
```

### 主干 B：从自转公转到四季（"时间与季节是算出来的"）

```
KP10 自转特征（方向/周期/速度）
   ├─ KP11 昼夜交替与晨昏线
   │    └─ KP12 地方时与区时
   │         └─ KP13 日期变更与两条日界线
   └─ KP14 地转偏向力

KP20 公转特征（轨道/速度/周期）
   └─ KP21 黄赤交角 23°26′  ← 全系列因果起点
        ├─ KP22 太阳直射点的回归运动
        │    ├─ KP23 昼夜长短的纬度与季节变化
        │    ├─ KP24 正午太阳高度（公式与年变化）
        │    ├─ KP25 太阳视运动与日出日落方位
        │    └─ KP26 四季更替与五带划分
        └─ KP27 二十四节气（黄经每 15° 一个节点）
```

### 主干 C：从地表到地心再回到地表（"地球是活的"）

```
KP30 地震波与地球内部圈层（莫霍面/古登堡面/莱曼）
   ├─ KP31 岩石圈与软流层
   └─ KP32 板块构造学说与六大板块
        ├─ KP33 生长边界与消亡边界（地震火山成带）
        └─ KP34 内力作用与地表形态（褶皱/断层/火山）

KP40 大气垂直分层
   └─ KP41 大气受热过程（削弱/保温/逆辐射）
        └─ KP42 热力环流与常见局地环流
             └─ KP43 气压带风带（七压六带）与移动
                  └─ KP44 季风与气候成因

KP50 水循环
   ├─ KP51 海水性质（温度/盐度/密度）
   └─ KP52 海水运动（波浪/潮汐/洋流）
        ├─ KP53 洋流分布规律与四大渔场
        └─ KP54 海气相互作用（厄尔尼诺/拉尼娜）

KP60 外力作用与地貌类型（河流/喀斯特/风成/海岸/冰川）
   └─ KP61 地貌观察与剖面判读
        └─ KP62 自然灾害与灾害链、地理信息技术
```

**因果强度最高的三条边**（做视频优先打这三条，观众最容易"哦——"）：
1. `KP21 → KP22 → KP23/KP24/KP25`：一个 23°26′ 的倾斜，导出四季、极昼、影子方位。
2. `KP30 → KP31 → KP32`：一个波速突变，导出"地核是液态铁"。
3. `KP41 → KP42 → KP43`：一次"地面先热起来"，导出全球风带与季风。

## 2. 可视化难度分级（决定用哪种做法）

| 等级 | 特征 | 做法 | 涉及知识点 |
| --- | --- | --- | --- |
| ★ 易 | 静态结构、剖面 | 生图 + 缓慢推镜 | KP06、KP30、KP40、KP60 |
| ★★ 中 | 一个连续旋转/位移 | 图生视频，参考图锁死角度 | KP01、KP02、KP10、KP52 |
| ★★★ 难 | 多体相对运动（日—地—光） | 先算数据再动画，需两视角对照 | KP11、KP22、KP23、KP24、KP25 |
| ★★★★ 极难 | 需精确几何一致（晨昏线、光照图） | 用代码生成（three.js + 公式），或严格按计算帧绘制 | KP11、KP25、KP27 |

对 ★★★ 以上的知识点，**不要靠文生视频"想象"**，一定按 `docs/10` 的公式算帧。
AI 生成地球光照最容易犯三个错：晨昏线不过地心、光线不平行、夜半球方向反了。

## 4. 一页速记：地球的 12 个关键数字

| 量 | 数值 | 用途 |
| --- | --- | --- |
| 地球年龄 | 约 46 亿年 | 开场数字 |
| 赤道半径 / 极半径 | 约 6378 km / 6357 km | 说明"不是正球" |
| 黄赤交角 | 23°26′（23.44°） | 四季的总开关 |
| 回归线纬度 | 23°26′ | ±δ 极值 |
| 极圈纬度 | 66°34′ | 90° − 23°26′ |
| 自转周期（恒星日） | 23 h 56 min 4.09 s | 反直觉钩子 |
| 自转周期（太阳日） | 24 h | 日常时间 |
| 赤道自转线速度 | 约 1670 km/h（465 m/s） | "你正以高铁 5 倍速移动" |
| 公转周期（恒星年 / 回归年） | 365.2564 d / 365.2422 d | 闰年由来 |
| 日地平均距离（1 AU） | 约 1.496 亿 km | 尺度感 |
| 近日点 / 远日点 | 约 1.471 亿 / 1.521 亿 km（1 月初 / 7 月初） | 破除"夏天更近"迷思 |
| 太阳常数（总太阳辐照度） | 约 1361 W/m²（大气顶、垂直入射） | 能量计算 |
| 全球平均接收 | 约 340 W/m²（考虑球面与反射） | 气候能量收支 |

> 溯源：TSI 1361 W/m² 取 NASA SORCE/TSIS 观测值（此前常用 1366–1368 W/m²，教材口径可能不同，视频里建议说"约 1360 W/m²"更稳）；
> 恒星日 23h56m4.09s、恒星年 365.25636 d、回归年 365.24219 d 为天文常数常用值。
