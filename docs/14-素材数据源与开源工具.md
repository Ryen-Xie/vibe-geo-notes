# 14 · 素材、数据源与开源工具

> 做地球类可视化，**素材的质量决定成片的下限**。这一节收录的都是"能查到授权、能用在商业内容里"的源。

---

## 1. 地球影像与地形（首选）

| 素材 | 来源 | 许可 | 用途 |
| --- | --- | --- | --- |
| **Blue Marble**（蓝色弹珠，含 Next Generation 月度版） | NASA Goddard / NASA SVS | NASA 内容一般不主张版权，可免费使用；不得暗示 NASA 背书，禁用 NASA 标识 | 地球贴图、开场地转、季节变化对比 |
| **NASA Earthdata**（MODIS、VIIRS、SRTM 等） | NASA | 开放获取，需按引用规范署名 | 云量、海温、反照率、地形高程 |
| **NASA SVS**（科学可视化工作室） | NASA | 公共使用，可下载成片与素材 | 太阳活动、地球系统动画参考 |
| **NOAA**（GOES 卫星云图、海温） | NOAA | 美国政府作品，公共领域 | 实时云图、台风过程 |
| **USGS**（地震目录、地形、Landsat） | USGS | 公共领域 | 地震打点、地貌影像 |
| **Natural Earth**（矢量与栅格底图） | naturalearthdata.com | **公共领域** | 国界、海岸线、行政底图（做"示意图"首选） |
| **OpenStreetMap** | OSM 贡献者 | **ODbL 1.0**（署名 + 衍生数据库相同许可） | 城市尺度底图；做视频贴图须署名 |
| **Copernicus Sentinel 数据** | 欧盟 Copernicus | 免费开放（需注明来源） | 高分辨率地表、海冰、洪水范围 |
| **ESO / ESA 图像** | ESO、ESA | 多为 CC BY 4.0（须逐张确认） | 深空、星云、天文背景 |

**注意**：NASA 素材虽可免费用，但**不要**在画面里出现 NASA 徽标，也不要写成"NASA 联合出品"。

## 2. 中国境内合规要点（重要）

| 事项 | 规则 | 去向 |
| --- | --- | --- |
| 地图底图 | 中国地图必须使用**标准地图**或经审核的地图，并标注**审图号** | 自然资源部"标准地图服务"（bzdt.ch.mnr.gov.cn）免费下载 |
| 国界表达 | 不得漏绘、错绘国界线，不得漏绘南海诸岛、钓鱼岛等 | 同上，直接下载标准版使用 |
| 自制示意图 | 明确标注"示意图，非标准地图"，慎用于正式内容 | 建议直接套用标准地图底图 |
| 天地图 / 高德 / 百度 底图截图 | 受服务条款限制，商业视频使用需看其授权 | 查看各平台开放平台条款 |
| 教材插图 | 版权归出版社 | **不可直接截取**，需自绘或换公共领域素材 |

> 一句话：**凡是有国界的图，先找审图号；没有审图号就别发。** 这是这类内容唯一可能"一条视频毁掉一个号"的地方。

## 3. 开源库与 GitHub 仓库（可直接用/参考实现）

| 项目 | 说明 | 许可 |
| --- | --- | --- |
| [three.js](https://github.com/mrdoob/three.js) | WebGL 事实标准，球体 + 自定义 shader 做地球最灵活 | MIT |
| [Cesium](https://github.com/CesiumGS/cesium) | 专业级 3D 地球/地形/影像，带时间轴，做"真实地球"最省力 | Apache-2.0 |

| [Echovagant/3D-earth](https://github.com/Echovagant/3D-earth) | **面向高中地理学习**的 3D 地球 + 课程地图，Vue3 + three.js，纯静态 | 见仓库 LICENSE |

## 5. 数据可信度分级（引用前自检）

| 级别 | 来源类型 | 例 |
| --- | --- | --- |
| A | 官方机构、同行评议论文 | NASA、NOAA、USGS、中国地震台网、Nature/Science |
| B | 权威科普、教科书级机构 | 中国科协科普中国、中科院各所科普栏、NASA SVS |
| C | 百科、媒体、行业网站 | 维基百科（可作线索，不作终稿依据） |
| D | 自媒体、教辅机构推文 | 只作选题灵感，**必须回查 A/B** |

> 视频里出现的每个数字，都应当能回到 A 或 B 级来源。这一条写进制作规范，长期看比任何技巧都值钱。
