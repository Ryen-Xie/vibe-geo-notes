# 03 · 宇宙环境与太阳（KP01-KP06）

---

## KP01 天体与天体系统

### 原理
宇宙中的物质存在形式统称**天体**：星云、恒星、行星、卫星、流星体、彗星、星际物质。
天体之间相互吸引、相互绕转，形成**天体系统**，层级由小到大：

```
地月系 → 太阳系 → 银河系（与河外星系并列） → 可观测宇宙
```

要点：
- 层级判断的唯一标准是**"谁绕谁转"**，不是"谁大谁小"。
- 月球绕地球转 → 地月系；地球等行星绕太阳转 → 太阳系；太阳绕银河系中心转 → 银河系。
- 银河系直径约 10 万光年，太阳距银心约 2.6 万光年。

### 可视化点
- 用"镜头连续拉远"一条运动完成：地表 → 月球轨道 → 行星轨道 → 银河旋臂 → 星系群。
- 关键是**同一帧里只保留一级系统的轨道线**，否则观众会晕。拉远时上一条轨道淡出。

### 易错
- 把"总星系"当独立层级（现多用"可观测宇宙"）。
- 认为流星体是"掉下来的星星"——它是星际空间的固体小块，进入大气才发光。

### 溯源
天体系统层级为中学教材通用表述；银河系尺度取天文常用值（直径约 10 万光年）。

## KP02 太阳系结构与行星分类

### 原理
八大行星按距日由近及远：**水、金、地、火、木、土、天、海**。
按性质分三类：

| 类型 | 成员 | 特征 |
| --- | --- | --- |
| 类地行星 | 水星、金星、地球、火星 | 体积小、密度大、岩石表面、卫星少 |
| 巨行星 | 木星、土星 | 体积大、密度小、气态为主、卫星多、有环 |
| 远日行星 | 天王星、海王星 | 距日远、温度低、冰质 |

公转三大共同特征：**同向性**（都自西向东）、**共面性**（轨道面接近同一平面）、**近圆性**（偏心率小）。
火星与木星之间有小行星带。

### 可视化点
- 做"轨道尺度"时用对数刻度或分层缩放，并标注"距离为对数示意"。
- 让八大行星同屏公转，速度按真实周期比（水星最快、海王星最慢），观众自然看出"内快外慢"。

### 易错
- 冥王星不是八大行星（2006 年被划为矮行星）。
- 行星本身不发光，靠反射太阳光；"金星最亮"是因其反照率高且距离近。

## KP03 地球的普通性与特殊性

### 原理
**普通**：从质量、体积、距日位置看，地球只是类地行星中普通一员。
**特殊**：目前已知唯一存在高级智慧生命的天体。条件拆成四条：

| 条件 | 机制 | 反事实（如果没有） |
| --- | --- | --- |
| 日地距离适中 | 地表平均温度适宜（约 15℃），水可以液态存在 | 太近→水沸腾；太远→全球冰封 |
| 质量、体积适中 | 引力足以保持大气层；内部有足够热量维持地质活动 | 太小→大气逃逸（像火星）；太大→厚重大气与高压 |
| 恒星光照稳定 | 太阳处于主序星阶段，寿命长、输出稳定 | 光度剧变→气候系统崩溃 |
| 宇宙环境相对安全 | 大小行星各行其道，地球有木星"清道夫"减少撞击 | 撞击频率高→生物大灭绝频繁 |

### 可视化点
- "四个条件"用四象限或四层同心护盾呈现，每层被"关掉"时地球画面同步恶化（升温、大气剥离、冰封、撞击）。
- 这是天然的反事实教学法，适合 60 秒冷知识。

### 素材建议
用 NASA 的地球与火星真实影像做对比（公共领域，见 docs/14）。

## KP04 太阳辐射

### 原理
- 能量来源：太阳内部**核聚变**（氢聚变为氦），核心温度约 1500 万 K，表面约 5800 K。
- **总太阳辐照度（TSI，旧称太阳常数）**：在大气顶、垂直于光线方向，约 **1361 W/m²**（NASA SORCE/TSIS 值；早期文献为 1366–1368 W/m²）。
- 因地球是球体、且约 30% 被反射，**全球平均到达地表系统**约 **340 W/m²**。
- TSI 并非恒定，随太阳活动有约 0.1% 的 11 年周期波动。

### 影响太阳辐射到达地面的四个因子（高频考点）
| 因子 | 影响方式 |
| --- | --- |
| 纬度 | 太阳高度越大，穿过大气路径越短，被削弱越少；低纬总量大 |
| 大气厚度与透明度 | 云量多、尘埃多、水汽多 → 削弱强（如四川盆地、重庆） |
| 地势 | 海拔高，空气稀薄、尘埃少 → 太阳辐射强（如青藏高原） |
| 天气与日照时数 | 晴天多、降水少 → 年总量大（如西北地区） |

### 对地球的意义
维持地表温度 → 驱动水循环与大气运动 → 提供生物光合作用能量 → 形成煤、石油等化石能源（储存的古代太阳能）。

### 可视化点
- 做一条"光线穿过大气"的路径对比：低纬短路径 vs 高纬长路径，用光线颜色深浅表示削弱量。
- 用一个"一米阳光"的正方形收光面 vs 地球曲面的对比，讲清"为什么全球平均只有 340 W/m²"。

### 易错
- 把"太阳辐射强"等同于"气温高"：青藏高原太阳辐射最强但气温低（海拔高、大气保温弱）。
- 把太阳常数当成"地表收到的能量"。

### 溯源
TSI = 1361 W/m²、全球平均 340 W/m²、周期波动 0.1%：NASA SORCE/TSIS 与 NASA Earth Observatory 能量收支资料。

## KP05 太阳活动与日地相互影响

### 原理
太阳大气由内到外：**光球 → 色球 → 日冕**，不同层出现不同活动：

| 层 | 主要活动 | 特征 |
| --- | --- | --- |
| 光球 | **黑子** | 温度比周围低，故显暗；黑子多少是太阳活动强弱的标志 |
| 色球 | **耀斑、日珥** | 耀斑是色球局部突然增亮，能量释放最剧烈 |
| 日冕 | **太阳风** | 带电粒子流向外抛射，可到达地球 |

- 周期约 **11 年**（黑子相对数变化的周期）。
- 对地球的影响：扰动电离层 → 影响无线电短波通信与导航；扰动磁场 → 磁暴、指南针失灵；高纬出现极光；影响卫星与航天器安全、电网。

### 可视化点
- "11 年心跳"：用一条黑子相对数曲线做心电图式脉冲，同步画面给太阳表面黑子数量变化。
- 极光镜头用真实极光影像 + 磁力线示意图叠化。
- 灾害链用"耀斑 → 电离层 → 短波中断 / 导航误差 / 电网波动"三路分支动画。

### 易错
- 黑子"黑"不是因为没光，而是温度较低（约低数百 K）。
- 极光不是太阳风"吹"到高纬，而是带电粒子沿磁力线进入高层大气并激发发光。

### 溯源
太阳大气分层、黑子/耀斑/太阳风为教材通用内容；11 年周期与 TSI 波动见 NASA SVS 太阳活动资料。

## KP06 地质年代与地球演化（衔接"地球的历史"）

### 原理
地球年龄约 **46 亿年**。地质年代从大到小：**宙 → 代 → 纪 → 世**。

| 宙 | 代 | 关键事件（时间量级） |
| --- | --- | --- |
| 前寒武纪（冥古宙、太古宙、元古宙） | — | 地球形成、原始海洋、最早生命（约 35 亿年前）、大气由无氧到含氧 |
| 显生宙 | 古生代（寒武—奥陶—志留—泥盆—石炭—二叠） | 寒武纪生命大爆发（约 5.4 亿年前）、鱼类→两栖→蕨类森林、二叠纪末生物大灭绝 |
| 显生宙 | 中生代（三叠—侏罗—白垩） | 爬行动物（恐龙）繁盛、裸子植物、白垩纪末大灭绝（约 6600 万年前） |
| 显生宙 | 新生代（古近—新近—第四纪） | 哺乳动物与被子植物繁盛、人类出现、第四纪冰期 |

生物学与地理学交叉点：**化石是地层年代的"时钟"**，简单生物化石出现在老地层、复杂生物在新地层。

### 可视化点
- 把 46 亿年压缩成 24 小时：人类出现在最后几秒——极强的尺度震撼。
- 用"地层叠蛋糕"逐层长出化石，配时间轴。

### 易错
- 古生代不是"最古老"；前寒武纪才是。
- 恐龙灭绝与人类出现之间隔了约 6400 万年，不是"紧接着"。
