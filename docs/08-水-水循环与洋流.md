# 08 · 水：循环、海水与洋流（KP50-KP54）

---

## KP50 水循环

### 三种循环
| 类型 | 路径 | 意义 |
| --- | --- | --- |
| **海陆间循环**（大循环） | 海面蒸发 → 水汽输送 → 陆上降水 → 地表/地下径流 → 回海 | 使陆地水不断更新，最重要 |
| **陆地内循环** | 陆面蒸发、植物蒸腾 → 降水回陆地 | 补充内陆降水（如内陆干旱区） |
| **海上内循环** | 海面蒸发 → 降水回海面 | 水量最大，但与人类关系小 |

### 主要环节
蒸发、水汽输送、降水、地表径流、下渗、地下径流、蒸腾。

### 人类活动怎么改它
| 活动 | 影响 |
| --- | --- |
| 修水库 | 调节径流的季节分配，增加蒸发与下渗 |
| 跨流域调水 | 改变地表径流的空间分布 |
| 城市化（硬化地面） | **下渗减少、地表径流增大、汇流时间缩短** → 更易内涛 |
| 植树造林 | 增加下渗与蒸腾，削峰补枯 |
| 过度抽取地下水 | 地下径流减少、地面沉降 |

### 可视化点
- 一个"闭环水流"动画，五种颜色对应五个环节，箭头带粒子流。
- "城市内涛"对比镜头：草地 vs 水泥地，同一场雨的下渗与径流量对比——生活钩子极强。

### 易错
- 认为"水循环使水资源取之不尽"——淡水更新速度有限，局部超采会枯竭。
- 把"下渗"与"地下径流"混为一谈。

## KP51 海水性质

### 温度
- 表层水温随**纬度升高而降低**；
- 同一纬度，**暖流经过的海区温度偏高**、寒流偏低；
- 垂直方向：随深度增加而降低（深层变化很小）。

### 盐度（高频考点）
全球表层盐度分布呈"**马鞍形**"：**副热带海区最高（约 35‰）**，赤道略低（降水多），高纬最低（蒸发弱、融冰淡水多）。

影响盐度的因素：
| 因素 | 影响 |
| --- | --- |
| 降水量与蒸发量 | 蒸发 > 降水 → 盐度高（副热带） |
| 径流注入 | 大河入海口盐度低（如亚马孙河口、长江口） |
| 洋流 | 暖流增盐、寒流减盐（相对） |
| 海区封闭程度 | 封闭 + 强蒸发 → 极高（红海 >40‰，死海更高） |

### 密度
与温度负相关、与盐度正相关。深层海水因低温高盐而密度大，是驱动**深层环流**的关键。

### 可视化点
- 一张"纬度—盐度"曲线（马鞍形），标出赤道、副热带、高纬三个点，再叠红海/波罗的海两个极端案例。

## KP52 海水运动

| 形式 | 成因 | 特征 |
| --- | --- | --- |
| 波浪 | 风（主要）、地震（海啸） | 风浪大小取决于风速、风时、风区 |
| 潮汐 | 月球与太阳的引潮力 | 一天两次涨落；**明月（农历初一、十五）为大潮**，上下弦为小潮 |
| 洋流 | 盛行风、密度差、地转偏向力、海岸地形 | 大规模、相对稳定的海水流动 |

## KP53 洋流：分布规律与四大渔场

### 1) 按性质分
- **暖流**：从低纬流向高纬（水温高于所经海区）；
- **寒流**：从高纬流向低纬（水温低于所经海区）。

### 2) 分布规律（记三条就够）
| 海区 | 规律 | 大陆岸别对应 |
| --- | --- | --- |
| 中低纬海区（副热带环流） | 北半球**顺时针**、南半球**逆时针** | 大陆**东**岸为暖流，**西**岸为寒流 |
| 中高纬海区（副极地环流） | 北半球**逆时针**（气旋型） | 大陆东岸为寒流，西岸为暖流 |
| 南半球 40°S 附近 | 西风漂流（寒流性质），环南极一圈 | —— |

### 3) 四大渔场与成因
| 渔场 | 位置 | 成因 |
| --- | --- | --- |
| **北海道渔场** | 日本暖流 + 千岛寒流交汇 | 寒暖流交汇，海水扰动上泛，饵料丰富 |
| **纽芬兰渔场** | 墨西哥湾暖流 + 拉布拉多寒流交汇 | 同上（历史上曾极盛，现已衰退） |
| **北海渔场** | 北大西洋暖流 + 北冰洋南下冷水 | 寒暖流交汇 + 宽广大陆架 |
| **秘鲁渔场** | 秘鲁沿岸 | **上升补偿流**（离岸风把表层水带走，深层冷水上涌） |

### 4) 洋流的影响
- 气候：暖流增温增湿（西欧温带海洋性气候）、寒流降温减湿（南美西岸荒漠）；
- 生物：渔场、藻场；
- 航行：顺流省时省油，逆流费时；冰山与海雾风险；
- 污染：扩大污染范围，也加快净化。

### 可视化点
- 一张世界洋流图，用"红/蓝流线"动态流动，箭头带粒子。转成俯视全球旋转视角，观赏性很强。
- 渔场成因用一个"剖面"：两支不同颜色的水流相撞 → 海水上泛 → 浮游生物繁殖 → 鱼群聚集。这个剖面镜头非常"教材级正确"且好看。

### 易错
- 认为"寒流一定从南极来"。
- 把秘鲁渔场也归为"寒暖流交汇"（它是上升流成因，**没有**寒暖流交汇）。
- 混淆"洋流流向"与"风带方向"。

## KP54 海气相互作用：厄尔尼诺与拉尼娜

### 正常年份（沃克环流）
赤道太平洋：西侧（印尼附近）受热上升、降水多；东侧（秘鲁附近）下沉、干燥；表层暖水向西堆积，深层冷水在东侧上涌（支撑秘鲁渔场）。

### 厄尔尼诺
- 赤道东太平洋海面温度**异常升高**，信风减弱，暖水东移；
- 西太平洋（印尼、澳大利亚）降水减少 → 干旱与林火风险；
- 东太平洋（秘鲁）降水增多 → 洪涛；上升流减弱 → **渔场减产**。

### 拉尼娜
- 与厄尔尼诺相反：东太平洋更冷、信风增强、西侧降水更多。

### 可视化点
- 一张赤道太平洋剖面，左（西）右（东）两支垂直环流箭头 + 海温色带。把海温色带从"西暖东冷"翻转成"东暖"，整个环流反向——一个镜头讲完两种现象。
