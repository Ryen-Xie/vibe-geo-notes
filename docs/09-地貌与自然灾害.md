# 09 · 地貌与自然灾害（KP60-KP62）

---

## KP60 外力作用与地貌

### 五种外力作用
**风化 → 侵蚀 → 搬运 → 堆积 → 固结成岩**（前四者往往同时进行，只是主导者不同）。

| 作用 | 含义 | 结果 |
| --- | --- | --- |
| 风化 | 岩石在原地被破坏（物理/化学/生物） | 风化壳、碎石 |
| 侵蚀 | 外力带走物质 | 谷地、凹槽、崖壁 |
| 搬运 | 物质被输送 | —— |
| 堆积 | 物质在低处/缓处沉积 | 扇、三角洲、沙丘 |

### 五类地貌速查
| 类型 | 典型形态 | 主导作用 |
| --- | --- | --- |
| **河流地貌** | 上游 V 形谷、中游曲流与牛铃湖、出山口冲积扇、入海口三角洲、河谷阶地 | 侵蚀（下蚀/侧蚀）+ 堆积 |
| **喀斯特地貌** | 石林、溶洞、天坑、峰丛（溶蚀）；钟乳石、石笋（淀积） | 流水溶蚀（化学作用） |
| **风成地貌** | 风蚀蘑菇、雅丹、戈壁（侵蚀）；新月形沙丘（堆积） | 风力 |
| **海岸地貌** | 海蚀崖、海蚀柱（侵蚀）；沙滩、沙嘴（堆积） | 海浪 |
| **冰川地貌** | U 形谷、角峰、刃脊（侵蚀）；冰砂垒、漂砾（堆积） | 冰川 |

### 河流地貌的关键因果
```
上游：落差大、流速快 → 下蚀为主 → V 形谷
中游：流速减慢 → 侧蚀为主 → 曲流、牛铃湖、河漫滩
出山口：坡度骤减 → 堆积 → 冲积扇（扇形、颗粒由粗到细）
入海口：流速最慢 + 海水顶托 → 三角洲
```

### 可视化点
- 一条河从源头流到入海，一镜到底（"河道飞行"视角），每一段地貌在镜头经过时高亮命名。这条镜头是地理视频的经典语法。
- 喀斯特剖面：地表石林 + 地下溶洞 + 滴水成钟乳石，用"水沿裂隙下渗"的粒子流贯穿上下。

### 易错
- 冲积扇在**出山口**、三角洲在**入海口**，两者极易混淆。
- U 形谷是**冰川**侵蚀，V 形谷是**流水**侵蚀——形状就是证据。
- 雅丹是**风蚀**（垄槽相间），沙丘是**风积**。

## KP61 地貌观察

### 观察顺序（由大到小）
宏观（大地形轮廓、走向）→ 中观（坡面、河谷）→ 微观（岩性、颗粒、层理）。

### 四个观察维度
| 维度 | 看什么 |
| --- | --- |
| 高度 | 绝对/相对高度、海拔 |
| 坡度 | 陡缓、坡面变化（凸/凹/直） |
| 坡向 | 阳坡/阴坡（影响光照与植被） |
| 组合 | 地貌的组合关系（山—谷—扇—洲） |

### 剖面判读三步
1. 定方向与比例尺；
2. 找地层界面与不整合面（判断先后）；
3. 读出"哪一层被切穿"→ 越晚的地质事件越靠后。

## KP62 自然灾害与地理信息技术

### 分类
| 类型 | 例子 | 主要成因 |
| --- | --- | --- |
| 气象水文灾害 | 洪涛、干旱、台风、寒潮 | 大气环流异常、降水极端化 |
| 地质灾害 | 地震、滑坡、泥石流、地面塌陷 | 内外力作用 + 人类活动 |
| 生物与海洋灾害 | 病虫害、赤潮、风暴潮 | —— |

### 灾害链（很有讲头的概念）
一个灾害触发下一个：
```
地震 → 滑坡/坪塞湖 → 溃决洪涛 → 泥石流
台风 → 暴雨 → 内涛 / 风暴潮
干旱 → 蝗灾 / 林火 → 大气污染
```
> 做视频时用"多米诺"动画，最能说明"防灾要打断链条而不是只救一个环节"。

### 地理信息技术（3S）
| 技术 | 作用 | 关键词 |
| --- | --- | --- |
| **RS**（遥感） | 获取面状信息、监测范围与变化 | "看" |
| **GNSS/GPS**（定位） | 定位与导航、形变监测 | "定" |
| **GIS**（地理信息系统） | 分析、叠加、制图、决策 | "算" |

典型题：灾害范围监测（RS）→ 受灾点定位（GNSS）→ 风险区划与撤离路径（GIS）。

### 可视化点
- 灾害链用"骨牌"或"电路过载"的视觉隐喻。
- 3S 技术用一个"三层叠加"的镜头：遥感影像底图 + 定位点 + 分析结果图层逐层出现。
