# 15 · 版权与合规台账

> 这份文档解决一个问题：**哪些东西能放进仓库、能放进视频、能商用，哪些只能放链接。**
> 结论先行：**知识可以讲，表达不能抄；地图要审图号；字体音乐要有授权。**

---

## 1. 三条判断原则

### 原则一：思想与表达二分
地理规律、公式、事实、数据、地名、年份 —— 属于"思想/事实"，**不受版权保护**，随便讲。
教材的段落组织、例题措辞、插图、表格设计 —— 属于"表达"，**受保护**，不能整段搬。

所以：**用自己的话把同一件事讲一遍，完全合法**；把教辅某页扫描进仓库，不合法。

### 原则二：合理使用要看四要素（中国《著作权法》第二十四条同理）
1. 使用的目的与性质（教学/评论/新闻报道 vs 商业变现）；
2. 作品的性质；
3. 使用部分的数量与实质性（**引用要短、要是必要部分**）；
4. 对作品潜在市场的影响（**不能替代原作**）。

结论：做知识视频引用一小段原文并标注出处，通常风险低；把整章教辅做成"免费替代品"，风险高。

### 原则三：商业内容按最严格标准执行
一旦接广告、带货、卖课，就属于商业使用，"教学合理使用"的辩护空间大幅缩小。**按最严格标准做，才不会有后患。**

## 2. 资源分类台账（详细版见 `data/copyright-ledger.csv`）

### 2.1 教材（人教版/湘教版/中图版/鲁教版等）

| 项 | 状态 |
| --- | --- |
| 正文、插图、表格、习题 | **受版权保护**，版权归各出版社 |
| 章节标题、目录结构 | 事实性信息，可引用，但不宜"整套目录照抄"做成产品 |
| 使用方式 | ✅ 引用一句并标注"据××版教材第×章"；❌ 截图整页、扫描 PDF、逐段改写后仍保留原结构 |
| 建议 | 用**自己的章节组织**（本仓库即如此），只对齐知识点，不对齐文字 |

### 2.2 教辅与题库（学科网、全品、21 世纪教育网、各地模拟卷等）

| 项 | 状态 |
| --- | --- |
| 试题原文、解析、导学案、课件 | **受版权保护**（汇编作品 + 单题著作权） |
| 使用方式 | ✅ 参考题型与考法，自己重新命题；❌ 搬运题目到仓库、做成"免费题库" |
| 注意 | 部分平台还禁止"抓取/转载"，违反的是平台条款（合同责任），与著作权是两回事，两条都可能踩 |

### 2.3 高考真题

| 项 | 状态 |
| --- | --- |
| 试题文本 | 一般由命题机构（教育部教育考试院及各省考试院）享有权利；官方评析文章另有版权 |
| 使用方式 | ✅ 讨论"某年某卷考了××考点"这类事实；✅ 短引用单题并标注来源用于评析；❌ 整卷汇编、❌ 做成付费题库 |
| 建议 | 视频里说"这类题在近五年出现过"，比直接念题干更安全，也更有信息量 |

### 2.4 课程标准与官方文件

| 项 | 状态 |
| --- | --- |
| 课标正文 | 官方文件，可引用；**转载全文需谨慎**，不宜作为自己的产品内容 |
| 使用方式 | ✅ 引用条目编号与要点并标注出处；❌ 全文复制进仓库当"资料" |

### 2.5 图片、视频、音频素材

| 类型 | 判定 |
| --- | --- |
| NASA / NOAA / USGS / Natural Earth | 基本公共领域或免费使用，署名即可（详见 docs/14） |
| OSM | ODbL：必须署名 "© OpenStreetMap contributors"，衍生数据库需同许可 |
| ESO / ESA / Copernicus | 逐张确认（多为 CC BY 4.0 / 免费开放 + 署名） |
| 影视截图、纪录片片段、他人动画 | ❌ 高危，除评论目的短引用外不要用 |
| 网络搜索到的图（含教辅网站配图） | ❌ 默认不可用，"网上找的"不是授权 |

### 2.6 字体与音乐

见 docs/14 §4。**字体和 BGM 是短视频侵权投诉的第一大来源**，务必留授权截图。

### 2.7 AI 生成内容

| 项 | 提示 |
| --- | --- |
| 生成图/视频 | 各平台用户协议不同，商用前查条款；多数平台允许商用但不保证独占 |
| 风格模仿 | "模仿某位在世艺术家风格"存在争议，尽量用"写实科普风"这类中性描述 |
| 真实人物/品牌 | 不要生成可识别的真实人物、品牌标识、官方徽标 |

## 3. 实操规则（写给我们自己看的）

| 场景 | 规则 |
| --- | --- |
| 写知识点 | 合上教材自己写；写完再对照检查有无漏项，**不看原文下笔** |
| 必须引用原文 | 单处不超过必要长度的短引用，加引号 + 标注"来源：××，第×页" |
| 需要教材插图 | 改为自绘示意图，或替换为公共领域素材 |
| 需要真题 | 自己改写成"同考点的新情境题"，并在仓库注明"自编" |
| 需要地图 | 用标准地图（带审图号）或 Natural Earth 自制并注明"示意" |
| 需要数据 | 回查 A/B 级来源，画面角标注明来源与年份 |

## 4. 地图合规专项（中国境内发布）

| 要求 | 做法 |
| --- | --- |
| 使用审核过的地图 | 自然资源部"标准地图服务"下载，保留**审图号** |
| 画面标注 | 角落显示"审图号 GS(20xx)xxxx 号" |
| 不得改动国界 | 不改边界、不漏绘南海诸岛与钓鱼岛、不改变比例造成误导 |
| 示意图 | 必须写"示意图，不作为国界依据" |
| 境外平台版本 | 同样适用；错误地图在境外平台同样会引发严重问题 |

## 5. 发布前 60 秒自检

- [ ] 没有任何一页教材/教辅/试卷的原文或截图
- [ ] 所有引用都有来源标注，且长度合理
- [ ] 所有图片素材可追溯到 docs/14 的某一项
- [ ] 地图有审图号，或明确标注"示意图"
- [ ] 字体、BGM 有授权记录，已登记台账
- [ ] AI 生成内容没有真实人物、品牌、徽标
- [ ] 没有把自编题标成"真题"
- [ ] 商业合作内容已按商业标准复核（引用更短、素材更保守）

---

## 6. 收到投诉/下架通知怎么办

1. **先下架，不争辩**。争议期间继续传播会放大损失。
2. 定位到具体素材（台账里的 ID 能一秒定位来源与授权情况）。
3. 若是误判：准备授权凭证（CC 链接、公共领域说明、购买记录）申诉。
4. 若是真侵权：替换素材、重剪重发，并在台账里把该素材标记为"禁用"。

> 台账的价值就在这里：**出事时能在十分钟内说清"这条素材哪来的"。**
