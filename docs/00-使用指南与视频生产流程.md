# 00 · 使用指南与视频生产流程

## 1. 这个仓库怎么用

一条知识视频的生产链条是：

```
知识卡（本仓库 docs/03-09） → 选题打分（本文 §2） → 脚本（钩子+三段结构）
      → 分镜表（docs/13） → AI 生图/生视频 → 配音/字幕 → 剪辑 → 发布
```

- **docs/03-09** 是"事实与原理层"，用来保证讲得对；
- **docs/13** 是"视听层"，用来保证好看；
- **docs/15** 是"法律层"，用来保证能发、能商用。

不要跳过第一层直接写分镜。地球专题最大的坑是：**画面很炫，但黄赤交角画错了 23.5° 还是 23.4°、晨昏线画成了过极点的大圆**——懂行的观众一眼就看出来，评论区会翻车。

## 3. 三种片长的结构模板

### A. 60 秒"反直觉冷知识"（抖音/视频号主力）

| 时间 | 内容 | 画面要求 |
| --- | --- | --- |
| 0-3s | **反直觉断言**（结论先行，不给解释） | 一个强对比画面，无字幕干扰 |
| 3-8s | 制造疑问："但你有没有想过……" | 镜头推进/旋转 |
| 8-45s | 三步解释，每步一个可视化动作 | 一段动画只讲一件事，轴锁定 |
| 45-55s | 回到生活：影子/航班/极光 | 实拍感画面或第一视角 |
| 55-60s | 一句金句 + 下集钩子 | 定格 + 标题字 |

### B. 3 分钟"原理讲解"（B 站/YouTube 主力）

四段式：**现象（30s）→ 机制（90s）→ 推演（40s）→ 迁移（20s）**
- 机制段必须给"可验证的中间量"：直射点纬度、时差分钟数、影长比例；
- 推演段做一个"如果……会怎样"的反事实（把黄赤交角改成 0°，四季消失）。

### C. 8 分钟"深度专题"（合集/系列片头）

五段式：现象 → 历史（谁发现的）→ 机制 → 数据（真实观测）→ 影响与迁移。
历史段是地球专题的天然优势：莫霍洛维奇 1909、古登堡 1914、莱曼 1936、魏格纳 1912——有具体年份和人物，故事性直接拉满。

## 4. 钩子公式（12 个可直接套用）

1. **否定常识**："一天其实不是 24 小时。"
2. **给出精确反例**："你手机上的 24:00，在恒星眼里是 23:56:04。"
3. **量化到荒谬**："地球每秒接收的太阳能，够全人类用 20 多分钟。"（用 docs/03 的算法自己算，别抄）
4. **悬念前置**："人类从来没挖穿过地壳的 1/500，却敢说地核是铁做的。"
5. **地域针对**："在新疆，晚上 10 点太阳还没落。"
6. **身份代入**："如果你在赤道上，你的体重会轻一点点——原因是自转。"
7. **时间压缩**："把一年压缩成 60 秒，你会看到一条蛇在南北回归线之间来回爬。"
8. **二元对立**："同一时刻，有人过生日，有人已经过完生日了。"
9. **成本核算**："为了让你家光伏板多发电 10%，支架要倾斜多少度？"
10. **文化钩**："二十四节气不是农历的装饰，它是一套用影子校准的太阳历。"
11. **灾难叙事**："全球地震不是随机撒的，它们排成了一条线。"
12. **反转收尾**："所以，四季不是因为地球离太阳近了。"

> 注意：钩子可以夸张，**但不能说错**。说过头了要立刻在 3 秒内补一句校正，否则评论区会揪住不放。

## 5. 视觉语言规范（地球专题专用）

| 项 | 规范 | 理由 |
| --- | --- | --- |
| 主色 | 深空蓝 `#0B1026` 打底，太阳用暖橙 `#FF7A29`，陆地用低饱和绿 | 与真实卫星影像观感接近 |
| 轴线 | 地轴永远画成发光细线，倾角固定 23.4°（口头说 23°26′） | 一致性，观众会记住 |
| 光照 | 太阳光一律画成平行光（不画点光源） | 这是教材级正确表达，也是"日地尺度"的正确直觉 |
| 比例 | 日地距离与地球直径**绝不按真实比例**，必须打字标注"示意，非等比例" | 避免误导；也是免责 |
| 运动 | 自转方向统一"自西向东"，从北极看逆时针 | 全系列不能反，否则前功尽弃 |
| 字幕 | 关键词高亮 + 数字用等宽字体 | 数字是这类内容的说服力来源 |
| 节奏 | 每 6-8 秒一次画面变化，每 15 秒一个信息点 | 完播率 |

## 6. AI 生成流程（实操顺序）

1. **先出静态帧**：每个关键构图先生成 1 张图（地球侧视、光照图、剖面图），确认角度对不对；
2. **再出运动**：用图生视频，提示词只写"运动"，不重写画面（画面已在参考图里）；
3. **复杂几何自己算**：直射点轨迹、太阳高度曲线，用 `docs/10` 的公式算成数据，画成折线/散点再动，比让 AI 猜更准；
4. **三视图交叉验证**：任何 3D 地球镜头，都要同时给出"北极上空视角"和"侧视"两个版本，看到底对不对。
