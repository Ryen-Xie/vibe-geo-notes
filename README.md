# vibe-geo-notes · 高中地理「地球」专题知识库

面向 **AI 动画 + 数据可视化** 形式的知识短视频（vibe 知识大赏类）而建的地理学资料底座。
核心选题：**高中地理 / 高考地理中「地球」这一整块**——宇宙环境、太阳、地球运动、圈层结构、板块构造，以及与之强关联的大气、水、地貌。

> 定位：不是题库搬运，而是**可直接写分镜的、结构化到镜头级的讲解资料**。
> 每一条知识点都带四件套：`原理 → 公式/判读 → 易错点 → 可视化点（怎么画成动画）`。

## 内容边界（重要）

这份资料库的正文**全部为原创改写**：原理、推导、判读方法、比喻、镜头设计都是重写的，
不是对教材、教辅、真题的复制。原因很实在：

1. 人教版/湘教版/中图版/鲁教版的教材正文、学科网·全品·21 世纪教育网等的教辅与课件、教育部教育考试院的真题，**都在版权保护期内**，整段搬进仓库会有下架和侵权风险，也不利于后续把视频做成商业内容。
2. 地理知识本身（规律、公式、事实、数据）不受版权保护，**可以自由讲**；受保护的是"特定表达"。所以做法是：**讲同一件事，用自己的语言和可视化重讲一遍**。
3. 所有受版权保护的资源，都在 [docs/15-版权合规台账.md](docs/15-版权合规台账.md) 与 `data/copyright-ledger.csv` 里**按条目登记**：来源、权利人、可做什么、不可做什么。想引用时先查台账，再决定"引用一小段 + 标注"还是"只用链接"。

## 一句话方法论

> 知识视频的竞争力不在"信息量"，而在**把抽象关系变成一条可以被眼睛跟住的运动轨迹**。
> 地球专题天然占优：黄赤交角、直射点、晨昏线、太阳高度，全都是"会动的几何"。
